# Travel Project
1. Build docker containers:
`docker-compose build` 
2. Start docker containers:
`docker-compose up -d`
3. In app_container load migrations:
`alembic upgrade head`

В моделі User замінено name на username, додано перевірку на унікальність (при створенні і при update)

На кожен рут додано response_model, додано Base Schema, яка повертає на порожні return сервісних функцій схему типу {"message": str}. Тобто тепер можна зробити чіткі моделі респонсу на кожен рут на мобільному застосунку. Є три типу респонсу: специфічні шеми, базова шема і {"detail": str} на респонси з помилкою.

Додано числове обмеження для кімнат (20). Кімната рахується, якщо запрошений користувач прийняв кімнату й кімната активна. !!! За потреби можна додати обмеження на кількість PENDING кімнат також (якщо буде час на се лишатись)
